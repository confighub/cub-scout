$ ./cub-scout trace deploy/api -n myapp-prod --explain

TRACE: deploy/api (namespace: myapp-prod)

  Owner:     ArgoCD
  App:       myapp-prod
  Source:    https://github.com/acme/myapp-deploy.git
  Path:      environments/prod
  Revision:  main
  Sync:      OutOfSync
  Health:    Degraded

  Chain:
    Git repo (acme/myapp-deploy.git)  [UNRESOLVABLE — repo does not exist]
     └─ ArgoCD Application (myapp-prod)
         └─ Deployment (api)
             └─ ReplicaSet (api-6d4f9c8b7)
                 └─ Pod (api-6d4f9c8b7-m4n2p)

  Explain:
    This workload is managed by ArgoCD Application "myapp-prod".
    The ownership labels are real. However, the source repository
    (acme/myapp-deploy.git) is a brownfield fixture — it does not
    resolve to a real Git repo. The Application shows OutOfSync
    because ArgoCD cannot fetch from a fictional source.
    cub-scout reports what the metadata says. It does not guess.
