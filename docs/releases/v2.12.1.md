# v2.12.1 - Reliable Headless Image Verification

**Published: 2026-09-20.** Previous release: v2.12.0. This patch
preserves the published v2.12.0 tag and artifacts. Readiness is tracked in
[#582](https://github.com/confighub/cub-scout/issues/582) and the
[evidence and execution checklist](image-verification-readiness.md).

## User Value

For a known digest-pinned literal OCI configuration release delivered through
a supported controller, check whether the intended configuration and complete
Deployment image evidence agree with the cluster, without a TUI.

Merged changes:

- #579 strengthens exact OCI source/release identity and Deployment proof:
  Pod -> ReplicaSet -> Deployment UID ownership, current template/generation,
  complete positive replica coverage and every regular container running/ready
  with the intended digest. Missing or ambiguous evidence remains unknown.
- #581 makes headless stdout failures fail the command and tests CLI/plugin/MCP
  output, saved reports, gated exits and bounded requests.
- #583 bounds credential helpers and HTTP error-body buffering, rejects
  malformed intended container lists, and adds reproducible live acceptance
  tooling and public evidence. Bounded credential helpers are deliberately
  non-interactive, even from a terminal. Windows descendant-process cleanup
  still requires an enclosing job timeout.

See the [image verification guide](../howto/is-this-image-deployed.md) for
commands, results and limits.

## Release Gates

- [x] Merged hardening with passing unit, integration and GitOps E2E CI.
- [x] Disposable real Argo/Flux OCI delivery: complete PASS, capped
  INCONCLUSIVE and configuration-drift BLOCK. Actual standalone/plugin checks
  agree on complete and capped cases.
- [x] Authenticated publication and direct HTTPS registry verification against
  a disposable local environment, without an OCI-layout fallback.
- [x] Clean-container installation and runtime checks using published binaries.
  The maintainer waived independent teammate sign-off on 2026-09-20.
- [x] Publish v2.12.1; download and checksum-verify its archives, validate actual
  standalone/plugin binaries, and verify the Homebrew update.

The downloaded Linux arm64 binary and installed plugin passed the Argo check
and returned INCONCLUSIVE with exit 2 for capped reads, missing credentials and
an untrusted CA. macOS arm64 passed version/help smoke tests. Archive checksums
and the Homebrew cask update were verified; Homebrew installation and Windows
runtime were not tested. See [published-binary evidence](../../examples/oci-release-check/published-binary-proof.json).

The authenticated run used a TLS proxy to the local ConfigHub OCI listener,
normal certificate validation and a scoped worker credential. Missing/invalid
credentials, denied target access and an untrusted certificate returned
INCONCLUSIVE. This does not test a hosted installation.

## Limits And Deferred Scope

PASS is a bounded, dated observation, not application functional success,
publication authority, continuous monitoring or an atomic Kubernetes snapshot.
Full ownership/completion image proof is Deployment-scoped. Other workload
adapters, multi-architecture index/platform resolution and image-only fleet
search are deferred to the future v2.13.0 candidate
[#584](https://github.com/confighub/cub-scout/issues/584), not this patch.
