# v1.13.0 Release Notes

> **Status:** Released 2026-04-14.
> Previous milestone: `v1.12.0` tightened governed proof for connected and Argo-managed workflows.

**Theme:** *Make connected proof easier to verify, easier for AI to route, and boringly green in CI again.*

This release packages the trust-surface work that came out of the governed cubbychat repeat runs after `v1.12.0`.

The focus is not new mutation power.
The focus is better evidence:

- more exact ConfigHub trust URLs
- more revision-aware guidance before sign-off
- stronger connected `history` handoff
- a clean release gate again

---

## What's New

### Canonical ConfigHub Trust URLs Across The Read Path

Connected read surfaces now do a better job surfacing the first useful ConfigHub page instead of making the operator or AI reconstruct it.

Included in this work:

- canonical unit detail URLs
- canonical revision-history URLs
- connected MCP `structuredContent` carrying those trust surfaces where available
- `trace` and `explain` carrying the same canonical URL family

This means the product can now hand off earlier to a real review surface, not just end with a generic “go check the GUI.”

### Revision-Aware Hints For Sign-Off

Connected hints are now more explicit about revision state.

Examples:

- `Head revision 9 is ahead of live revision 7; review revision history now before treating this unit as converged.`
- aligned revision states now suggest audit/review instead of falsely urgent drift language

This tightens the gap between:

- “show me proof”
- “would you sign off on this?”

### `history` Now Surfaces Connected Trust Guidance

`history --format json` now includes:

- `confighubUrl`
- `confighubRevisionsUrl`
- `nextSteps`

That gives AI clients and automation a better first governed receipt path for change history instead of forcing them to infer the next ConfigHub hop themselves.

### Release Hygiene Cleanup

This release also closes the pre-release noise that had started to blur signal:

- README install snippets now cover the same distribution channels as the install guide, including krew
- the connect-and-compare demo snapshots reflect the current doctor output
- the fixture-backed AI integration script now checks for the current scan output evidence
- `go test ./...` is green again
