# v0.20.0 Release Notes — Flux Operator Interop (Read-Only)

**Released:** 2026-02-12  
**Scope:** pre-1.0 operator workflow improvements without mutation paths

## Highlights

v0.20.0 adds a concrete Flux Operator interop slice focused on real operational
workflows while preserving `cub-scout`'s read-only model:

- CronJob and Job visibility
- Runbook-style action previews (no execution)
- Unified activity timeline
- Preview environment detection heuristics
- Trace source artifact provenance

## New `map` Commands

### `map cronjobs`

List CronJobs with:

- schedule
- suspension state
- active job count
- last schedule time
- derived run status
- owner attribution

```bash
cub-scout map cronjobs [--namespace <ns>] [--owner <owner>] [--format ascii|json|md]
```

### `map jobs`

List Jobs with:

- owning CronJob (when present)
- active/succeeded/failed counters
- derived run status
- owner attribution

```bash
cub-scout map jobs [--namespace <ns>] [--owner <owner>] [--format ascii|json|md]
```

### `map actions <kind/name>`

Read-only runbook previews for operational actions (for example rollout restart,
pod delete guidance, one-off Job from CronJob template).

```bash
cub-scout map actions <kind/name> -n <namespace> [--format ascii|json|md]
```

### `map activity`

Unified timeline from Flux/Argo/Helm/event signals.

```bash
cub-scout map activity [--namespace <ns>] [--owner Flux|ArgoCD|Helm] [--since 24h] [--format ascii|json|md]
```

### `map previews`

Detect ephemeral preview environments from deterministic label/annotation
heuristics (including Forgejo/Gitea hints).

```bash
cub-scout map previews [--namespace <ns>] [--stale-after 72h] [--format ascii|json|md]
```

## Trace Artifact Provenance

New `trace --artifacts` adds source artifact metadata to trace output:

- `url`
- `revision`
- `digest`
- `lastUpdateTime`
- `sourceKind`

```bash
cub-scout trace <kind/name> -n <namespace> --artifacts [--format ascii|json|md]
```

If provenance cannot be read, fields are explicit with `unknown` values.

## Output Contract (ASCII vs JSON)

- JSON remains the canonical contract for automation and integrations.
- ASCII/Markdown remain deterministic projections of JSON fields.
- New v0.20 command surfaces and `trace --artifacts` are covered by golden tests.
