# v1.9.0 Release Notes

> **Status:** Released 2026-04-05.
> Companion milestone: `v1.8.0` (AI gateway foundations) is documented in `docs/roadmap.md`.

**Theme:** *Verifiable import workflows and secret dependency visibility.*

This release closes the v1.9 milestone with two operator-facing outcomes:
- conformance workflows that can gate automation without mutating the cluster
- secret evidence that makes missing, unreadable, and cross-namespace dependencies visible without exposing secret values

---

## What's New

### Conformance Workflows

`cub-scout` now supports a tighter explore -> preview -> verify loop for import and comparison work:

- `compare three-way --fail-on <severity>`
  - adds threshold-aware conformance reporting and CI-friendly exit codes
  - keeps pure reporting mode available when `--fail-on` is omitted
- `import --resource <kind/name>`
  - supports curated import preview instead of whole-namespace selection only
  - surfaces selected, included, skipped, missing, and unsupported resources deterministically

Together, these let operators preview narrower import proposals and verify results with explicit pass/fail policy.

### Secret Evidence

Secret evidence is now available as safe metadata across CLI and TUI surfaces:

- `trace`
  - workloads: Deployment, StatefulSet, DaemonSet, Pod
  - Flux sources: GitRepository, HelmRepository, Bucket
  - Flux deployers: Kustomization, HelmRelease
  - Crossplane ProviderConfig with cross-namespace secret resolution
- `map issues`
  - fleet-style reporting for missing, unreadable, and unresolved secret references
  - skips optional missing references to avoid false-positive noise
- TUI trace panel
  - status summary plus individual secret entries with reference type and namespace context

Secret evidence remains metadata-only:
- no `.data`
- no `.stringData`
- no decoded secret payloads
- RBAC denial is reported as `unreadable`, not silently treated as `missing`
