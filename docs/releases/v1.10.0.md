# v1.10.0 Release Notes

> **Status:** Released 2026-04-09.
> Companion milestone: `v1.9.0` (secrets and conformance) is documented in `docs/roadmap.md`.

**Theme:** *Close the troubleshooting gap: Kubernetes events in explain and trace.*

This release ships the v1.10 wedge for #368 "Beat Argo CD GUI as the first stop for GitOps troubleshooting." The key P0 gap — Kubernetes events per resource — is now addressed.

---

## What's New

### Recent Kubernetes Events

`explain` and `trace` now surface recent Kubernetes events for the target resource:

```
cub-scout explain deploy/my-app -n prod

  Owner: ArgoCD
  Source: https://github.com/acme/app
  ...

  Recent Events:
  ⚠ 5m BackOff: Back-off restarting failed container (x3)
  ○ 10m Pulled: Successfully pulled image nginx:1.25
  ○ 12m Created: Created container app
```

Features:
- **Bounded**: Top 5 events shown (not a raw dump)
- **Prioritized**: Errors and warnings sorted first
- **Readable**: Human-friendly age format (`5m`, `2h`, `3d`)
- **Safe**: No secret data exposure

### JSON Contract

Both `explain --format json` and `trace --format json` include an `events` field:

```json
{
  "events": {
    "events": [
      {
        "type": "Warning",
        "reason": "BackOff",
        "message": "Back-off restarting failed container",
        "count": 3,
        "age": "5m",
        "severity": "warning",
        "source": "kubelet",
        "firstSeen": "2026-04-09T10:00:00Z",
        "lastSeen": "2026-04-09T10:05:00Z"
      }
    ],
    "totalCount": 10,
    "warningCount": 3,
    "errorCount": 1
  }
}
```

### Presentation Mode for Trace

`trace` now supports `--presentation=ai|human|paired`:

```bash
cub-scout trace deploy/nginx -n demo --presentation=ai
```

- AI mode: bracket notation, uppercase markers, `[end trace]` outro
- Human/Paired mode: title-case headings, owner info, ownership chain heading
- Legacy (no flag): preserves original formatting
