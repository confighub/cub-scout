# Actual v2.13 GoReleaser snapshot rehearsal

This is prepublication evidence, not v2.13 release acceptance. GoReleaser 2.18.2
ran the configured hooks from a normal clean Git checkout of `78d86d50`, using
Go 1.24.0 with cached dependencies. The version is `v2.13.0-next`; image tags are
local only. No artifact, image, Homebrew change or release tag was published.

[The receipt](v2.13-goreleaser-rehearsal.json) retains the source-bound metadata,
all sixteen binary hashes, all six archive hashes/entries, actual version/help
outputs and the local image identity. The private original logs, tools, archives
and verifier programs remain in `/tmp/scout-v213-goreleaser-20261005` and the
normal checkout in `/tmp/scout-v213-release-checkout-20261005`.

Success checks require each binary to embed the exact clean source revision,
Go 1.24.0, the `/v2` module and CGO disabled. Actual archive checks verify the
configured aliases, plugin `main` on Linux/Darwin only, exact documents and Unix
executable modes. Actual runtime smoke checks execute version and trace help for
the standalone, alias and plugin binaries on Darwin/Linux arm64 and amd64.
Execution uses an arm64 Mac and Docker with architecture compatibility support;
it is not native hardware acceptance for every architecture or controller proof.

The final Docker image must have matching declared architecture and embedded
binary, numeric nonroot UID/GID, the GitHub source label and snapshot version.
It executes with networking disabled, a read-only filesystem, all capabilities
dropped and no-new-privileges. These checks do not prove anonymous public pulls.

The rehearsal exposed and repaired missing tidy checksums, unignored output and
missing source stamping in a managed worktree. A normal clone corrects the last
case. Its origin must name the public repository to avoid a workstation-path
source label. A rejected Docker attempt labelled an amd64 binary as arm64 on the
arm64 host; the release configuration now explicitly selects the Linux amd64
standalone build and uses `--platform=linux/amd64`. Archive and image architecture
are checked independently; successful execution through emulation is insufficient.

Reproduce in a normal clean checkout of the exact source with Go 1.24.0 and
checksum-verified GoReleaser 2.18.2 available on PATH:

```sh
GORELEASER_CURRENT_TAG=v2.13.0 goreleaser check
GORELEASER_CURRENT_TAG=v2.13.0 goreleaser release --snapshot --clean --parallelism 2 --timeout 15m
```

The Windows binaries in this Mac-built archive packet remain unexecuted.
Independent configured [native Windows builds](v2.13-windows-runtime/NOTICE.md)
at `34d0af49` now pass eight actual version/help checks on amd64 and arm64,
including clean embedded source identity. They have different source stamps and
are not byte-identical copies of this packet. Public proxy,
Homebrew/plugin installs, anonymous image pulls, final tag tests and publication
remain open. This scoped proof does not close release sequence task 20 in full.
