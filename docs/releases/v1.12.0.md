# v1.12.0 Release Notes

> **Status:** Released 2026-04-11.
> Previous milestone: `v1.11.0` simplified the CLI surface and improved MCP/AI routing.

**Theme:** *Trustworthy proof for governed and Argo-managed workflows.*

This release tightens the two `cub-scout` proof surfaces that mattered most in the governed cubbychat repeat runs:

- `compare three-way` now reconnects governed resources instead of under-reporting them as disconnected
- `explain` is materially more authoritative for Argo-managed workloads

The result is a smaller gap between what operators can prove from the current cluster and what `cub-scout` can express directly.

---

## What's New

### `compare three-way` Reconnects Governed Resources

`compare three-way` now does a better job linking live workloads back to their governed source of truth.

Included in this fix:
- recover ConfigHub linkage from the owning Argo `Application` when the workload itself lacks `confighub.com/UnitSlug`
- preserve the inferred ConfigHub space and unit slug from the Argo source
- treat a reachable ConfigHub health endpoint as connected even when it returns a non-2xx HTTP status like `405`

This matters most in governed/Argo round-trip flows, where the old behavior could say:
- `partial`
- `disconnected`

even when governed state, Argo delivery, and live state all agreed.

With the new path, the exact command:

```bash
cub-scout compare three-way --scope deploy/frontend -n default --format json
```

can now return a true connected DRY/WET/LIVE agreement result for the governed demo resource.

### `explain` Is More Authoritative For Argo-Managed Workloads

`explain` now follows the owning Argo `Application` trace path when ownership detection already knows the workload is Argo-managed.

That means `explain` can now show:
- a real source instead of `unknown`
- a real deployment path instead of only `partial trace only`
- an honest degraded note when it had to fall back to kubectl-backed Argo inspection

For example, an Argo-managed deployment can now explain as:

```text
Owner: ArgoCD
Source: oci://oci.hub.confighub.com:443/unit/demo-roundtrip/cubbychat-wet
Deployed via: OCIRepository/... -> Application/... -> Deployment/frontend
```

instead of forcing operators to jump to `trace` just to recover the basic ownership chain.

## Why This Release Matters

The remaining friction in the governed demo is no longer basic diagnosis.

It is mostly about whether the tool can prove the right thing on the exact object without making the operator infer around blind spots.

`v1.12.0` is a trust release:
- less silent under-connection in `compare three-way`
- less fallback to `unknown` in `explain`
- a more honest path from symptom to governed proof
