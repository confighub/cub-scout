# v0.14.0 Release Notes

**Release Date:** 2026-02-03

## Summary

v0.14.0 adds portable output formats with the `--format` flag, enabling JSON and Markdown output for tree, trace, and map list commands.

## New Features

### `--format` Flag

All major output commands now support the `--format` flag:

```bash
cub-scout map list --format json    # Machine-readable JSON
cub-scout map list --format md      # Markdown (for docs/issues)
cub-scout trace deploy/x -n y --format json
cub-scout tree ownership --format md
```

Formats available:
- `ascii` (default) — Human-readable terminal output
- `json` — Structured JSON following v0.14 schema
- `md` — Markdown for embedding in documentation

### JSON Schema (v0.14)

JSON output follows strict determinism rules:

- **Lossless** — JSON contains all data; display limits are metadata only
- **Deterministic** — Same input = same output (no timestamps, stable ordering)
- **Joinable** — Canonical `ResourceID` objects for cross-referencing

Ordering guarantees:
- Owner groups: `[Flux, ArgoCD, Helm, ConfigHub, Native]`
- Resources: sorted by `(namespace, kind, name)`
- Trace chains: ordered by relationship

See `docs/v0.14-json-schema.md` for full specification.

## Contract Changes

- New `--format` flag for output commands
- `--json` preserved as shorthand for `--format json`
- JSON schema version: `v0.14`

## Breaking Changes

None. Existing `--json` flag continues to work.
