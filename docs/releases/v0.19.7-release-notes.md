# v0.19.7 Release Notes — Argo Lineage & v1 Readiness Audits

**Released:** 2026-02-09

## Highlights

This release adds **Argo App-of-Apps and ApplicationSet lineage** to ownership views, completes the **v1.0 readiness audit** from user feedback, and normalizes documentation for the upcoming stable release.

## Features

### Argo Lineage Support (#128, #132)

- **App-of-Apps parent/child lineage** now visible in ownership views
- **ApplicationSet → generated Applications** visible in `tree git`
- Consistent lineage representation across `tree ownership` and `tree git`
- Integration fixtures for both patterns

### Canonical Definitions (#129)

- Published canonical definitions of `workload` and `deployer`
- Aligned command behavior/output and docs to definitions
- StatefulSet parity in relevant commands

### Trace Context Hardening (#127)

- Detect stale/invalid Argo endpoint/context failures
- Print actionable remediation for trace errors
- Standardized command path to inspect/reset trace-related context
- Troubleshooting section with exact commands

## Documentation

### Canonical Migration Path (#130)

- Single canonical migration guide covering discovery/dry-run, import/apply, rollback/retry
- Examples for App-of-Apps, ApplicationSet, umbrella Helm
- Linked from getting-started and roadmap

### Archive Normalization (#133)

- Inventory of import-related archive docs: promote / keep-historical / remove
- Clear archive disclaimers for historical docs
- Index page: "Current Import Model" linking source-of-truth docs

## Infrastructure

### Argo Regression Audit (#125)

- Reproducible script comparing `v0.4.0` vs `v0.19.x` for tree commands
- CI-friendly fixtures for App-of-Apps and ApplicationSet
- Matrix/report with mismatch classification

### v1.0 Readiness (#123, #124)

- golangci-lint CI fixes
- Hardened docs, tests, and CI for v1.0 release

## Upgrade Notes

No breaking changes. Direct upgrade from v0.19.6 recommended.
