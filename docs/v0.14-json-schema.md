# v0.14 JSON Schema Specification

**Status:** Contract (pending implementation)
**Purpose:** Lock semantic meaning for sharable outputs
**Principle:** JSON is the complete truth; ASCII/MD are projections

---

## Design Constraints

1. **Lossless** — JSON contains ALL data; display limits are metadata only
2. **Deterministic** — Same input = same JSON (no timestamps, stable ordering)
3. **No UI concepts** — No cursor, panels, colors, widths
4. **Structured evidence** — Relationships proven with typed key/value pairs

---

## Determinism Rules (LOCKED)

**No time-derived fields by default:**
- No `timestamp`
- No `age`
- No `lastSeen`

If time is needed later: opt-in via `--include-time` flag (non-golden output).

**Ordering (applied everywhere):**
- Owner groups: canonical order `[Flux, ArgoCD, Helm, ConfigHub, Native]`
- Resources: sorted by `(namespace, kind, name)` lexicographically
- Trace chains: ordered by relationship (source → deployer → workload)

Note: Crossplane is not yet a first-class owner category. Crossplane-managed resources currently fall to "Native" until Crossplane detection is added to the canonical ownership model.

## Common Types

### ResourceID (canonical identity for joins)

```json
{
  "kind": "Deployment",
  "namespace": "web",
  "name": "frontend"
}
```

### Owner

```json
{
  "type": "Flux | ArgoCD | Helm | ConfigHub | Native",
  "ref": "ResourceID | null"
}
```

### Evidence (structured proof of relationship)

```json
{
  "type": "label | annotation | ownerRef | field | inventory",
  "key": "kustomize.toolkit.fluxcd.io/name",
  "value": "web-apps",
  "path": "metadata.labels"
}
```

Evidence types:
- `label` — Kubernetes label proving ownership
- `annotation` — Kubernetes annotation proving ownership
- `ownerRef` — metadata.ownerReferences entry
- `field` — spec/status field reference (e.g., spec.sourceRef)
- `inventory` — presence in GitOps inventory/resources list

### DisplayMeta (for ASCII/TUI rendering parity)

```json
{
  "maxItems": 3,
  "totalItems": 10
}
```

**Rule:** JSON `items` always contains ALL items. `displayMeta` indicates what ASCII would show.

## 1. Tree Schema

**Command:** `cub-scout tree ownership [--format json]`

**Purpose:** What exists, grouped by owner

```json
{
  "command": "tree",
  "subtype": "ownership",
  "context": {
    "cluster": "prod-us-east",
    "namespace": null,
    "filters": {
      "owner": null,
      "maxItems": 3
    }
  },
  "groups": [
    {
      "owner": "Flux",
      "displayMeta": {
        "maxItems": 3,
        "totalItems": 10
      },
      "items": [
        {
          "id": {
            "kind": "Deployment",
            "namespace": "api",
            "name": "backend"
          },
          "ownerRef": {
            "kind": "Kustomization",
            "namespace": "flux-system",
            "name": "api-apps"
          }
        },
        {
          "id": {
            "kind": "Deployment",
            "namespace": "web",
            "name": "frontend"
          },
          "ownerRef": {
            "kind": "Kustomization",
            "namespace": "flux-system",
            "name": "web-apps"
          }
        }
      ]
    },
    {
      "owner": "Native",
      "displayMeta": {
        "maxItems": 3,
        "totalItems": 2
      },
      "items": [
        {
          "id": {
            "kind": "Deployment",
            "namespace": "default",
            "name": "legacy-app"
          },
          "ownerRef": null
        }
      ]
    }
  ],
  "summary": {
    "totalResources": 12,
    "byOwner": {
      "Flux": 10,
      "Native": 2
    }
  }
}
```

**Ordering:**
- `groups` sorted by canonical owner order
- `items` sorted by `(namespace, kind, name)`

**Lossless guarantee:**
- `items` contains ALL resources for this owner
- `displayMeta.maxItems` indicates what `--depth N` would show in ASCII
- ASCII renders: first N items + `(+M more)` where M = totalItems - maxItems

## 2. Trace Schema

**Command:** `cub-scout trace <resource> [--format json]`

**Purpose:** Why this resource exists (ownership chain to source)

```json
{
  "command": "trace",
  "target": {
    "kind": "Deployment",
    "namespace": "web",
    "name": "frontend"
  },
  "chain": [
    {
      "id": {
        "kind": "GitRepository",
        "namespace": "flux-system",
        "name": "flux-system"
      },
      "role": "source",
      "relationship": "provides-manifests-to",
      "evidence": [
        {
          "type": "field",
          "key": "spec.url",
          "value": "https://github.com/org/repo",
          "path": "spec.url"
        }
      ]
    },
    {
      "id": {
        "kind": "Kustomization",
        "namespace": "flux-system",
        "name": "web-apps"
      },
      "role": "deployer",
      "relationship": "applies",
      "evidence": [
        {
          "type": "field",
          "key": "spec.sourceRef.name",
          "value": "flux-system",
          "path": "spec.sourceRef"
        },
        {
          "type": "inventory",
          "key": "status.inventory",
          "value": "Deployment/web/frontend",
          "path": "status.inventory.entries"
        }
      ]
    },
    {
      "id": {
        "kind": "Deployment",
        "namespace": "web",
        "name": "frontend"
      },
      "role": "workload",
      "relationship": "managed-by",
      "evidence": [
        {
          "type": "label",
          "key": "kustomize.toolkit.fluxcd.io/name",
          "value": "web-apps",
          "path": "metadata.labels"
        },
        {
          "type": "label",
          "key": "kustomize.toolkit.fluxcd.io/namespace",
          "value": "flux-system",
          "path": "metadata.labels"
        }
      ]
    }
  ],
  "summary": {
    "ownerType": "Flux",
    "source": {
      "kind": "GitRepository",
      "namespace": "flux-system",
      "name": "flux-system",
      "url": "https://github.com/org/repo"
    },
    "deployer": {
      "kind": "Kustomization",
      "namespace": "flux-system",
      "name": "web-apps"
    }
  }
}
```

**Chain ordering:** source → deployer → workload (root to leaf)

**Roles:**
- `source` — Git/OCI/Helm repository
- `deployer` — Kustomization, HelmRelease, Application
- `workload` — Deployment, StatefulSet, etc.
- `intermediate` — ReplicaSet, Pod (if included)

**Relationships:**
- `provides-manifests-to` — Source to deployer
- `applies` — Deployer to workload
- `manages` — Controller to child resource
- `selects` — Service to pods (label selector)
- `managed-by` — Workload back-reference to deployer

## 3. Ownership Schema

**Command:** `cub-scout map list [--format json]`

**Purpose:** Flat list of resources with ownership attribution

```json
{
  "command": "ownership",
  "context": {
    "cluster": "prod-us-east",
    "namespace": null
  },
  "resources": [
    {
      "id": {
        "kind": "Deployment",
        "namespace": "api",
        "name": "backend"
      },
      "owner": {
        "type": "Flux",
        "ref": {
          "kind": "Kustomization",
          "namespace": "flux-system",
          "name": "api-apps"
        }
      },
      "status": "Ready"
    },
    {
      "id": {
        "kind": "Deployment",
        "namespace": "web",
        "name": "frontend"
      },
      "owner": {
        "type": "Flux",
        "ref": {
          "kind": "Kustomization",
          "namespace": "flux-system",
          "name": "web-apps"
        }
      },
      "status": "Ready"
    },
    {
      "id": {
        "kind": "Deployment",
        "namespace": "default",
        "name": "orphan"
      },
      "owner": {
        "type": "Native",
        "ref": null
      },
      "status": "Ready"
    }
  ],
  "summary": {
    "total": 3,
    "byOwner": {
      "Flux": 2,
      "Native": 1
    },
    "byStatus": {
      "Ready": 3,
      "NotReady": 0
    }
  }
}
```

**Ordering:** `resources` sorted by `(namespace, kind, name)`

**Status values:** `Ready`, `NotReady`, `Unknown`, `Progressing`

## ASCII ↔ JSON Parity Examples

### Tree with depth limit

**Command:** `cub-scout tree ownership --depth 2`

**ASCII:**
```
Flux (10)
├── api/backend
├── web/frontend
└── (+8 more)

Native (2)
├── default/legacy-app
└── default/orphan
```

**JSON:** Contains all 12 items with `displayMeta.maxItems: 2`

### Trace

**Command:** `cub-scout trace deploy/frontend -n web`

**ASCII:**
```
Deployment web/frontend
  ↑ managed-by [label:kustomize.toolkit.fluxcd.io/name=web-apps]
Kustomization flux-system/web-apps
  ↑ sourced-from [spec.sourceRef.name=flux-system]
GitRepository flux-system/flux-system
  └─ https://github.com/org/repo
```

**JSON:** Same chain with structured evidence (see schema above)

---

## Contract Guarantees

- JSON output is deterministic (same input = same output)
- JSON is lossless (display limits are metadata, not data loss)
- JSON is joinable (canonical `id` objects for cross-reference)
- JSON has no timestamps by default
- Evidence is structured and bounded (proof, not raw dump)
